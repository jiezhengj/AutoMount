本文档定义 Feature `002-init-wizard-ux` 中命令行交互界面的契约、终端控制字符规范与菜单流转协议。

# 终端行读取与按键交互契约 (Terminal Line-Input Contract)

所有交互式字符串录入均通过通用函数 `promptLineWithEsc(prompt:)` 执行，遵循以下按键行为契约：

| 触发按键 | 字节码 / 序列 | 终端回显行为 | 返回状态 / 契约 |
| :--- | :--- | :--- | :--- |
| **`Esc` 键** | `0x1B` (ASCII 27) | 输出 `\r\u{1B}[K` 清除整行并打印 `(已取消)` | 返回 `nil`，调用方安全回退上级菜单。 |
| **退格键** | `0x7F` 或 `0x08` | 输出 `\u{08} \u{08}` 擦除末尾字符 | 删除当前缓冲区末尾字符。 |
| **回车键** | `0x0A` (`\n`) 或 `0x0D` (`\r`) | 输出换行符 `\n` | 返回缓冲区已修剪字符串（可能为空）。 |
| **非 TTY 环境** | - | 无单字符捕获，直接调用原生流读取 | 降级为常规阻塞读取，遇 EOF 返回 `nil`。 |

# 初始化向导契约 (`automnt --init`)

### 阶段一：扫描活跃卷宗与候选主机列表

程序启动即静默读取内核挂载表（`MNT_NOWAIT` 快照），提取所有 `smbfs` 卷宗并按主机地址聚合：

```text
=== automnt 初始化向导 ===
正在检测系统当前挂载的网络存储...
检测到以下候选主机：

  [1] 192.168.1.100 (检测到 2 个已挂载共享)
  [2] nas.local (检测到 1 个已挂载共享)

操作选项：
  [m] 手动添加新主机地址
  [s] 跳过主机配置 (稍后通过 automnt --config 配置)
  [d] 完成主机配置并进入下一步

请选择操作 [1-2 / m / s / d] (按 Esc 退出向导): 
```

### 阶段二：主机下钻与从属共享勾选

使用者点选主机（如 `1`）后，展开从属于该主机的共享多选菜单：

```text
--- 配置主机: 192.168.1.100 ---
请输入该主机的人类友好别名 (直接回车保持默认 [192.168.1.100], 按 Esc 取消): 家庭高速 NAS

请选择需要自动挂载的共享文件夹:
  [ ] 1. Public (smb://192.168.1.100/Public -> /Volumes/Public)
  [ ] 2. data-1 (smb://192.168.1.100/data-1 -> /Volumes/data-1)

输入编号切换选择 (例如 '1 2' 或 'all', 回车确认, 按 Esc 取消): all
  [✓] 1. Public (smb://192.168.1.100/Public -> /Volumes/Public)
  [✓] 2. data-1 (smb://192.168.1.100/data-1 -> /Volumes/data-1)
确认添加上述共享？[Y/n]: Y
已保存主机 [家庭高速 NAS] 的配置。
```

### 阶段三：循环登记与防重流转

保存后系统自动返回候选主机列表，已被选中的主机打上明确防重标记：

```text
检测到以下候选主机：

  [✓] 1. 192.168.1.100 [家庭高速 NAS] (已配置 2 个共享)
  [2] nas.local (检测到 1 个已挂载共享)

操作选项：
  [m] 手动添加新主机地址
  [s] 跳过主机配置
  [d] 完成主机配置并进入下一步

请选择操作 [1-2 / m / s / d] (按 Esc 退出向导): 
```

- 若使用者再次输入 `1`，终端提示：“该主机已配置，不可重复选择，请选择其他候选主机或点选 [d] 完成”。
- 使用者可继续点选 `2`，将其配置为第 2 顺位备选主机；亦可输入 `d` 结束主机录入。

### 阶段四：后台服务部署确认契约

完成更新策略选择后，系统进入后台服务部署确认节点：

```text
是否立即部署并在用户登录时自动运行后台守护服务？
  - 选择 [Y]: 自动安装 LaunchAgent，当网络环境变化时自动触发顺位挂载探测。
  - 选择 [n]: 仅保存配置文件，不向系统注册任何后台常驻服务。

请确认部署意愿 [Y/n] (默认 Y): n
已跳过后台服务部署。
配置已成功保存至: ~/Library/Application Support/automnt/automnt.plist
后续可通过运行 'automnt' 手动执行挂载，或使用 'automnt --config' 管理配置。
```

# 日常管理契约 (`automnt --config`)

日常配置以主机顺位为核心视图，提供完整的增删改查管理能力：

```text
=== automnt 日常配置管理 ===
活动配置文件: ~/Library/Application Support/automnt/automnt.plist (规范版本: 3.1.0)

当前配置的主机顺位列表 (探测时按由高到低排他执行):
  顺位 1: 192.168.1.100 [家庭高速 NAS] (启用的共享: 2 个)
  顺位 2: nas.example.org [远程备份节点] (启用的共享: 1 个)

管理操作：
  [1-2] 进入指定主机管理其从属共享
  [a]   新增主机 (扫描当前挂载 / 手动录入)
  [m]   调整主机顺位优先级
  [d]   删除主机 (支持清空所有主机)
  [u]   修改自动更新检查策略
  [q]   保存并退出 (按 Esc 等同放弃未保存修改退出)

请选择操作 [1-2 / a / m / d / u / q]: 
```

### 共享删除与维护子菜单契约

使用者输入 `1` 进入特定主机后：

```text
--- 主机管理: 192.168.1.100 [家庭高速 NAS] ---
当前从属共享:
  [1] Public (/Volumes/Public) [启用]
  [2] data-1 (/Volumes/data-1) [启用]

操作：
  [a] 从当前挂载卷追加共享 / 手动输入路径
  [d] 删除/移除指定共享
  [t] 切换启用/禁用状态
  [b] 返回上一级菜单 (或按 Esc)

请选择操作: d
请输入要删除的共享编号 [1-2] (按 Esc 取消): 1
已从主机移除共享 [Public]。
```

### 空配置保存与安全退出契约

若使用者通过 `[d]` 删除了全部主机：

```text
当前主机列表为空 (0 台主机)。
系统将该状态视为合法的静默休眠配置。
保存并退出配置？[Y/n]: Y
配置已更新。后台服务在被系统唤醒时将处于安全休眠状态。
```

# 异常与手动录入特定交互契约

### 1. 手动录入未挂载主机与从属共享交互契约

当使用者选择 `[m]`（向导）或进入新增主机选择手动录入时，触发以下交互流程（并在添加完成后精准展示钥匙串密码温和提示）：

```text
--- 手动添加主机 ---
请输入主机 IP 地址或域名 (按 Esc 取消): 192.168.1.200
请输入该主机的人类友好别名 (直接回车保持默认 [192.168.1.200], 按 Esc 跳过): 办公区备份机
正在测试主机 192.168.1.200 的 SMB 服务端口 (445)...
连接测试成功。

系统未在该主机下检测到已挂载卷宗，请手动录入共享路径：
请输入从属 SMB 共享路径 (格式如 smb://192.168.1.200/Backup, 按 Esc 取消): smb://192.168.1.200/Backup
标准目标挂载点将设置为: /Volumes/Backup
确认添加该共享？[Y/n]: Y

提示：对于手动添加的新网络共享，请确保已在 macOS 系统中成功连接过一次并勾选“在我的钥匙串中记住此密码”，认证凭据将由系统钥匙串自动安全管理。
已成功添加主机 [办公区备份机] 及其从属共享。
```

### 2. 目标主机网络不可达警示交互契约

若手动输入的主机 445 端口无法建立 TCP 握手：

```text
正在测试主机 10.0.0.99 的 SMB 服务端口 (445)...
⚠️ 警告: 无法连通目标主机 10.0.0.99 的 445 端口 (连接超时或网络不可达)。
该主机可能当前处于离线状态，或当前网络无法直连。
是否仍然添加该主机？[y/N]: y
已确认添加离线主机 10.0.0.99。
```

- 若使用者输入 `N` 或直接回车，终端提示 `已取消添加未连通主机` 并返回上一级。

### 3. 重复共享添加防呆提示契约

当使用者在某主机下再次添加已经存在的 SMB 共享时：

```text
请输入从属 SMB 共享路径: smb://192.168.1.100/Public
提示：共享路径 smb://192.168.1.100/Public 已存在于该主机名下，已自动忽略重复添加。
```
